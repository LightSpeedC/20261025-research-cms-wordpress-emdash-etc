素性とライセンス

EmDash は、Astro をもとにしたフルスタックの TypeScript 製 CMS。GitHub の説明文は「WordPress の精神的な後継」と名乗っている。ライセンスは MIT。

項目内容
提供元Cloudflare のブログが 1.0 を発表している
1.0 の公開2026-09-28 (Cloudflare のブログの公開日)
ライセンスMIT
GitHub のスター数13.9k (取得日 2026-10-25)
貢献者175 人超、1,800 コミット超、25 言語に翻訳 (Cloudflare の記述)

最初の公開は 2026-04-01 で、当時は v0.1.0 のプレビュー段階だった、と書く二次情報がある。公式で確かめたのは 1.0 の日付だけ。

構成と動作要件

EmDash は Astro の統合として入る。サイトと CMS が 1 つのプロジェクトにまとまり、管理画面は /_emdash/admin に出る。内容はデータベースに入り、管理画面・メディアライブラリ・メニュー・分類を備える。

項目要件
Astro6 以上のプロジェクト。アダプタ付きで output: "server"
Node.jsv22.16.0 以上
React管理画面の描画に使う
データベース入門手順はローカルの SQLite。ほかの対応先は Astro の資料に一覧が無かった
ログイン初回のセットアップで、サイト情報・管理者・パスキーを登録する

新規は create emdash@latest で始める。

配備先

配備先内容
CloudflareWorkers で動く。GitHub は「D1 + R2 + Workers」と書く。プラグインは Dynamic Worker として動く
Node.js任意の Node.js サーバ。SQLite を使う。プラグインは workerd (Cloudflare のオープンソースの実行環境) を別プロセスで起動して隔離する

デモは Cloudflare のアカウント無しで、Node.js と SQLite だけで動く。

プラグインと安全性

隔離

各プラグインは、自分専用の保存領域だけを持つ隔離された実行環境で動く。追加の権限は、プラグインが宣言し、サイト管理者が承認したときだけ付く。

レジストリ

  • AT Protocol の上に作られている。公開者はパッケージとリリースの記録に署名し、自分のアカウントに保存する。
  • 入れる前に、署名・チェックサム・パッケージ名・版・求める権限・ビルドの来歴を検証する。
  • モデレーションは EmDash のカタログから隠すだけで、リリースや所有者は変えない。
  • 無料のプラグインに対応済み。有料は将来の予定。

そのほか、1.0 の発表は、MCP サーバ (組み込み) ・ CLI ・ API による AI エージェントからの操作と、アルファ段階の AI サイトビルダ「EmDash Build」を挙げている。

プラグインの隔離は配備先ごとに仕組みが違う (Cloudflare は Dynamic Worker、Node.js は workerd の別プロセス)。公式の説明を読んだ範囲で、実際の隔離の強さは確かめていない。

WordPress との違い

今回取得した公式情報だけで比べる。

観点WordPressEmDash
ライセンスGPLv2 以降MIT
実行基盤PHP 8.3 以上 + MariaDB / MySQLNode.js v22.16.0 以上 (Astro 6 以上) または Cloudflare Workers
サイトとの関係CMS がサイトを描画するAstro のプロジェクトの中に統合する
プラグインの安全脆弱性の 91% がプラグイン。公開時に 46% が未修正 (Patchstack)隔離された実行と、署名つきのレジストリが前提
利用の広さ全サイトの 39.6% (W3Techs)1.0 が出て約 1 か月。利用の統計は未確認

⚠️ 注意 EmDash の安全性の設計は有望だが、実績はまだ短い。1.0 から約 1 か月で、脆弱性の報告数や運用の事例は、今回の調査では見つかっていない。
